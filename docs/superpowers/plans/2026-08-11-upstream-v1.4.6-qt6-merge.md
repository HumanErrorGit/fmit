# Upstream v1.4.6 / Qt6 Merge Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring the fork's `master` from v1.3.3 up to upstream v1.4.6, migrating from Qt5/MinGW to Qt6/MSVC, while keeping the four downstream additions (DSP test harness, Errorbuild branding, project docs, `-lglu32` fix).

**Architecture:** Toolchain first, verified against an untouched upstream checkout, so a later build failure is unambiguously the merge's fault and not the toolchain's. Then a merge commit (three conflicts), then a separate commit that strips the now-dead Qt5 compatibility layer, then the test harness and docs catch up.

**Tech Stack:** Qt 6.8.3 (`win64_msvc2022_64`), MSVC 2022 Build Tools, vcpkg (`fftw3:x64-windows`), qmake + jom, FFTW3, OpenGL.

Spec: `docs/superpowers/specs/2026-08-11-upstream-v1.4.6-qt6-merge-design.md`

## Global Constraints

- **Qt6 only.** No `QT_VERSION_CHECK` guards, no dual Qt5/Qt6 support, no `qt5-legacy` branch. Qt 6.8.3 is the target.
- **MSVC 2022 only** for local Windows builds. The MinGW toolchain at `F:\Qt\Tools\mingw810_64` is no longer used by this project. Do not remove MinGW-specific branches from `.pro` files — they still serve Linux and other machines.
- **C++98-compatible style** in application code, per `CLAUDE.md`: member variables `m_`, statics `s_`, `//` comments only. Existing Qt6 code from upstream stays as upstream wrote it.
- **Install paths:** everything on `F:` — `F:\Qt` (Qt), `F:\vcpkg` (vcpkg), `F:\VS\BuildTools` (MSVC), `F:\FMIT-Error\fmit\build-qt6` (build dir). C: has ~13 GB free and must not be filled.
- **`FFT_LIBDIR` is passed to qmake as `F:/vcpkg/installed/x64-windows`** (forward slashes). Upstream CI hardcodes `C:\vcpkg`; do not copy that path into any tracked file.
- **History:** merge, never rebase. No force-push to `origin`.
- **Never commit** build output, `aqtinstall.log`, or anything under `build-qt6/`.
- **Branding string is exactly** `Free Music Instrument Tuner - Errorbuild (Version ...)`, and the icon badge text is exactly `DEV` in colour `QColor(0xE8, 0x4A, 0x1A)`.
